# Web Reverse v0.24.1 · Windows x64 体验版

内置 AI Agent 的 Firefox 浏览器，用于网页请求分析、JS / JSVMP / WASM 逆向与自动化。把页面、目标接口和待分析字段交给侧栏 Agent，在本地生成并运行 Node.js / Python 脚本。

## 下载与使用

- **安装版**：下载 `web-reverse-v0.24.1-windows-x86_64.exe`，运行安装向导，从开始菜单打开 **Web Reverse**。
- **便携版**：完整解压同名 `.zip`，运行 `firefox/firefox.exe`，保留整个文件夹。
- 适用于 Windows 10/11 x64；已内置 VC 运行库、Node.js/npm 和 Python/pip，无需编译或单独安装这些运行时。
- 打开侧栏的 Web Reverse 星光入口 → 设置模型账号并点击“保存并使用” → 打开一个本地工作目录 → 选择全自动或 AI 辅助模式 → 输入目标。
- 模型账号由用户自行准备。需要登录的目标页面，请先完成登录。

## 本版内容

- 安装器、开始菜单、浏览器和侧栏品牌统一为 **Web Reverse**。
- 提供连续工具执行、页面与网络分析、本地文件和脚本执行、独立浏览器环境及本地记忆。
- 沿用原安装目录、内部注册键与配置标识。旧版用户升级前请备份完整 profile 与工作目录，安装时选择原位置。
